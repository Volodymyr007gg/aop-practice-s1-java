1. Яку з чотирьох провалених задач розв'язує git log?
git log розв'язує задачу яку хость змінив і команда git log --format='%h %an <%ae> %s'
показує автора, пошту, коміт, тобто зміну завжди видно.

2. Яку — git diff?
git diff розв'язує задачу яка вже змінилась і показує точно різницю версії рядком за рядків.

3. Яка задача не має розв'язку аж до заняття 10?
Розв'язку не має та задача яка поєднуює робоити, наприклад коли двоє людей одночасно працюють з одним і тим самим файлом який не розв'язується, тобто задача чекає на branches і merge.
